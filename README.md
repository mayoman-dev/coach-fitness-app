# Coach · training app

A mobile-first, offline-capable workout logger for a 6-week Push / Pull / Legs block (Nov 30, 2026 – Jan 10, 2027), plus the Nov 18–29 ramp-up.

- Static site: plain HTML/CSS/JS, no build step, no backend.
- All data stays in the browser's localStorage on the device. Use Export JSON for backups.
- Add to Home Screen for an app-like, offline experience.
